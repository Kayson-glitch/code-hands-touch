# 流体墨迹蓝色核心过大调整

## 问题

手部 hover 的流体墨迹扩散时，蓝色（核心色）占比过大，黄色外层太薄，拖尾中段已被玫红/蓝色主导。

## 根因

1. 采样浓度被放大了 `1.25` 倍，导致较低的真实浓度就被映射到蓝色端。
2. `dyeAt` 使用线性分段，0.5~1.0 区间全是「玫红→蓝」，蓝色过渡带过宽。
3. 暗部网点额外加了 `d * 0.1` 的浓度偏移，使阴影区域更容易进入蓝色。

## 调整方案

全部改动集中在 `src/components/HalftoneHandsFooter.tsx`：

1. **降低浓度放大倍数**
   - 将绘制循环里的 `fluid.sample(x, y) * 1.25` 改为 `* 1.0`。
   - 蓝色只保留在鼠标正下方浓度最高的核心。

2. **让渐变非线性偏移**
   - 在 `dyeAt(t)` 入口处加幂曲线：`Math.pow(t, 1.6)`。
   - 大部分拖尾停留在黄色/玫红，蓝色仅出现在 t 接近 1 的极小核心。

3. **减弱暗部网点对蓝色的加成**
   - 将 `dyeAt(Math.min(1, dye * 0.9 + d * 0.1))` 中的 `d * 0.1` 降为 `d * 0.02`。
   - 避免阴影区域因自身密度而自动偏蓝。

4. **（可选）降低颜色混合强度**
   - 如仍觉蓝色抢眼，可将 `mix = smoothstep(dye) * (0.45 + d * 0.55)` 的上限从 `1.0` 压到 `0.85` 左右，让灰阶底色更多保留。

## 验收

- 鼠标快速划过后，拖尾外围以黄色为主，中段玫红，仅笔尖处极小范围为蓝。
- 静止后墨迹消散过程中不再出现大面积蓝色斑块。
- 手部本身的灰阶体积感不被颜色覆盖破坏。
