# 修复进度条左右透明度渐变

参照图 image-159：当前模块标签居中亮白，左右相邻标签是**逐渐淡出并被裁到画面外**的，而不是在灰块宽度内硬裁断。现在的实现把轨道限制在灰块宽度内且渐变区太窄，所以看不到左右淡出。

## 调整内容（仅样式，src/styles.css）

1. 轨道容器不再等宽于灰块，改为“可视范围更宽 + 居中对齐灰块中心”：
   - 容器宽度扩展到灰块两侧各溢出约一个 slot 宽度（用负 margin 保持中心与灰块中心一致），高亮标签仍精确落在灰块中心。
2. 左右渐变遮罩加强并覆盖溢出区：
   - `mask-image: linear-gradient(90deg, transparent 0, rgba(0,0,0,1) 28%, rgba(0,0,0,1) 72%, transparent 100%)`，同时加 `-webkit-mask-image`，保证两侧标签是渐隐而不是硬边。
3. 相邻标签间距调整（`--slot-w`）使左右两侧各露出约半个标签，与参照图一致。
4. 字号 12/20、当前项 #FFFFFF、相邻项 28% 白保持不变。
5. 991–1246px 断点同步更新对应变量，保持中心对齐与渐变宽度比例一致。

## 不改动

模块切换动画、滚动交互、网格与十字准心、灰块与文案布局。
