# 调大静态手部透明度呼吸幅度

## 目标

让第一屏静态手部点阵的透明度呼吸更明显，从几乎不可见的 0.94–1.0 改为 0.8–1.0。

## 改动

- `src/components/HalftoneHandsFooter.tsx` 第 65 行：
  - 将 `ALPHA_BREATH_AMP` 从 `0.06` 改为 `0.2`。
  - 绘制循环里已有 `alphaBreath = 1 - sin(...) * ALPHA_BREATH_AMP`，因此新范围为 0.8–1.0（上限由 canvas 自动钳制到 1.0）。

## 验收

- 不滚动、不移动鼠标时，手部网点整体会有肉眼可见的明暗脉动。
- 滚轮驱动手部动画、流体墨迹 hover、入场视频/UI 动画视频交接逻辑均不变。
