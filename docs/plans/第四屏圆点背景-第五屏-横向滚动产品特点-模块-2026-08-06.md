# 第四屏圆点背景 + 第五屏「横向滚动产品特点」模块

## 1. 第四屏黑屏加圆点矩阵

第四屏（ClosingSection）的黑色反相层目前是纯色。给它加上与第二屏完全一致的圆点纹理：

- 纹理参数沿用第二屏：`radial-gradient(rgba(255,255,255,0.08) 2px, transparent 2.4px)`，`background-size: 40px 40px`，左右各留 100px 边距。
- 纹理只出现在黑色 reveal 层内部（跟着 clip-path 一起被抹出来），白底阶段保持干净，不出现灰点。

## 2. 新增第五屏：横向滚动的产品特点画廊

参考视频的交互：整屏钉住，滚动条驱动一排「图片 + 说明文字」面板从右向左横向平移，每段有 `[001]`～`[005]` 编号，卡片进入视口时轻微上浮/渐显，背景是黑底圆点矩阵。

结构与行为：

- 黑底（`#0A0A0A`）+ 同款圆点矩阵，`data-dark-section`，让导航与底部对话条自动切到暗色。
- 外层高轨道（约 5 段 × 每段行程）+ `position: sticky; top: 0; height: 100dvh` 的舞台；滚动进度 `p` 映射为轨道 `translate3d(-x, 0, 0)`，行程 = 内容总宽 − 视口宽。
- 每段：左侧竖版图片卡（约 220×300，1px 描边 + 品牌渐变描边光晕），右侧等宽说明栏，编号在卡片左上方，标题/正文用 Montserrat（正文 14/22），关键词用 `#5749FF`。
- 首段带一个大标题块（类似视频里的 EXPLORE），文案走 AI 智能客服主题，随横向滚动一起被推出画面。

五段内容（AI 智能客服）：

1. `[001] Instant Answers` — 秒级首响，7×24 无休。
2. `[002] Brand Voice` — 学习品牌语气与知识库，回复口吻一致。
3. `[003] Smart Routing` — 复杂工单实时识别并转交人工。
4. `[004] Omnichannel` — 网页、App、邮件、社媒统一对话上下文。
5. `[005] Insight Loop` — 自动归因高频问题，反哺产品与话术。

配图：用 AI 生成 5 张统一风格的竖版视觉（深色科技感、品牌蓝紫渐变高光），保持与视频里画廊卡片相同的构图比例。

## 3. 滚轮手感与第三屏一致

- 复用已接入的 Lenis 全局惯性滚动，进度在 `lenis.on("scroll")` 同帧读取，避免延迟一帧的"发涩"。
- 进度映射沿用第三屏公式量级：`p = (vh - top - vh*0.25) / (height - vh*0.8)`，横向位移套 `easeOutCubic`，卡片渐显用列进度前 1/3 同款缓动。
- `prefers-reduced-motion` 下退化为纵向堆叠列表，不做钉住与横向平移；≤990px 同样退化为纵向卡片。

## 4. 验证

Playwright 在 1440×900 与 1280×800 下分段截图（p=0/0.25/0.5/0.75/1），确认：五段依次横向经过、末段收尾不被裁切、第四屏交接无跳动、导航与对话条暗色切换正确、无控制台报错。
