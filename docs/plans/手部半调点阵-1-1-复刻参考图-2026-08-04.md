# 手部半调点阵 1:1 复刻参考图

只改手部渲染（`src/components/HalftoneHandsFooter.tsx`），页面结构、开场视频、文案与其他 UI 不动。

## 参考图的实际规律（已量测）

对参考图取样后得到几个关键事实，当前实现全部偏离：

- **墨色是单一中灰**：最深的点也只到 156–179 灰阶（约 `#9c9c9c`–`#b3b3b3`），纸面 251–254。当前实现从 `#c9c9c9` 一路压到 `#111111`，所以看起来又黑又脏。
- **明暗只由点面积表达**，不由颜色深浅表达。参考图里所有点是同一个灰，小点=亮、大点=暗。
- **网格是严格正交、间距恒定的**，高覆盖处的点大到几乎相接、边缘变成圆角方块（而不是继续长成圆形大团）。
- **溶解是"孤点飞散"**：主体外围保留很多极小的单点，密度按距离逐渐稀释，而不是整块淡出。
- **没有整体渐变遮罩**：亮部直接留白，不做上下左右的软淡出。

## 具体改动

1. **墨色改为固定单灰**：所有点使用同一颜色（约 `#a4a4a4`），最暗处允许轻微加深到 `#8f8f8f`，彻底删掉 `LIGHT_GREY → DARK_GREY` 的大跨度渐变。
2. **点面积重建**：半径 = 半格距 × sqrt(密度)（面积正比于密度，符合真实半调），最大填充到 0.98 格距，让暗部点几乎相接。
3. **点形状随覆盖率过渡**：覆盖率低时画圆，高于约 0.75 时用圆角方形（超椭圆近似）绘制，复刻参考图暗部"方块化"的观感。
4. **密度映射重做**：先对原图做局部归一化（当前原图 75% 分位仍是 0，全在暗部），再走接近线性的响应，保证从极小点到接近相接的点有连续过渡。
5. **溶解改为孤点飞散**：去掉 `FADE_X/FADE_Y` 的矩形软遮罩，改为按密度做随机保留（低密度处保留概率低但点尺寸不再继续缩小），外圈形成参考图那种零散单点。
6. **抖动去带状**：加入 4×4 有序抖动到密度阈值，消除大面积同尺寸点造成的色带。
7. **保留交互**：轻微视差与呼吸维持现状（幅度不变），只是作用在新的点阵上。

## 验收

用 Playwright 截图手部区域，与参考图并排核对：墨色是否落在中灰区间、暗部点是否相接方块化、外围是否有孤点飞散、中间调是否连续。
