# 手部 Hover 效果体验切换器

## 目标

在首屏半调点阵手部区域增加一个临时切换器，让用户可以现场体验 3 种 hover 反馈，确认后再把选定方案固化进组件。

## 当前状态

- `src/components/HalftoneHandsFooter.tsx` 负责渲染手部点阵。
- 手部目前为静态定格（最后一帧），滚轮驱动逻辑保持不变。
- 背景为 `#FAFAFA`，点阵使用中性灰阶（最深 `#a8a8a8`）。

## 实施步骤

### 1. 增加临时切换器 UI

- 在手部区域右上角（或底部居中）放置一个极小的切换条：
  - 三个选项：「磁吸」「加深」「呼吸」
  - 当前选中项高亮
  - 样式使用现有中性灰 tokens，不引入新彩色
- 切换器只在调试/体验阶段显示，最终可隐藏或保留为设置入口。

### 2. 实现三种 hover 模式

所有模式共享：

- 监听 `pointermove` / `pointerleave` 获取相对手部的光标位置
- 使用缓动变量（lerp，~0.12）平滑过渡，避免抖动
- 鼠标离开时 300ms 内复位
- 不影响滚轮驱动的帧索引逻辑

#### A. 局部磁吸

- 以光标为中心，半径 ~160px 内的网点向光标方向偏移
- 偏移量随距离衰减，最近处偏移 ~8px
- 同时放大 10-15%（面积驱动，保持点阵可读）
- 越靠近光标，点越“被吸过去”

#### B. 油墨加深

- 以光标为中心，半径 ~180px 内的网点墨色向最深档偏移
- 暗部点密度提升约 15-25%，中间调对比增强
- 使用现有 `INK_STOPS` 插值，不引入新颜色
- 移出后平滑回到原始密度

#### C. 网点呼吸

- 整体手部进入缓慢呼吸：全局缩放 ±2%，周期 ~3.2s
- 光标处产生向外扩散的涟漪，波纹半径随时间扩大
- 网点大小随波纹起伏：波峰 +12%，波谷 -5%
- 涟漪在光标移动时重新触发，旧涟漪自然淡出

### 3. 渲染集成

- 在 `draw()` 循环中读取当前模式与光标状态
- 对每帧点阵应用对应变换/颜色/缩放
- 保持 60fps，避免全量重采样；变换在绘制时直接应用

### 4. 验证

- 用 Playwright 分别切换三种模式并截图
- 确认鼠标移入/移出过渡平滑、无卡顿
- 确认滚轮控制手部动画与页面滚动逻辑未被破坏

## 验收标准

- [ ] 切换器可见并可点击切换三种模式
- [ ] 每种模式下 hover 都有明显且克制的反馈
- [ ] 鼠标离开 300ms 内平滑复位
- [ ] 滚轮驱动、第一帧定格、可回滚等原有逻辑不受影响
- [ ] 性能保持 60fps（无全量重采样）

## 备注

- 切换器为临时体验用；用户确认最终方案后，可移除切换器并把选中模式作为默认 hover 行为。
- 不引入彩色光效，保持现有中性灰阶与极简质感。
