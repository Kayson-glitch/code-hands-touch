# 把项目完整迁移到 Cursor 本地开发

## 结论先说

这个项目**没有数据库、没有登录、没有后端数据**，所以没有「数据导出」这件事需要做。要迁移的只有两样：

1. **代码** —— 通过 GitHub 同步，Cursor 里直接克隆。
2. **图片 / 视频素材** —— 目前存在 Lovable 的素材库里（图片、logo、开场视频、dashboard 截图共 12 个），代码里引用的是 Lovable 平台专用地址。**在本地会全部加载不出来**，必须先落地成项目里的真实文件。这是这次迁移唯一的真正工作量。

## 步骤

### 1. 代码同步到 GitHub（你操作）

在 Lovable 右上角 GitHub 菜单里连接仓库并同步。之后在 Cursor 里：

```
git clone <你的仓库地址>
cd <项目目录>
bun install
bun run dev
```

打开 http://localhost:8080。

### 2. 素材本地化（我操作，同步前先做）

我会把这 12 个素材全部下载进项目的 `public/media/` 目录，并把代码里的引用改成本地路径：

- 手部帧图 `hands-frames.webp`（第一屏点阵手的全部帧）
- 开场视频 `intro-hands.mp4`
- dashboard 截图、4 个 kore 图标、5 个 logo

改完后本地和 Lovable 上表现完全一致，不再依赖 Lovable 素材库。

### 3. 本地环境注意事项

- 用 **bun**（项目锁文件是 bun 的）。Node 只用来兜底，混用会出问题。
- 需要 Node 22 以上，你当前环境已满足。
- 不需要任何环境变量 / API key：项目里没有密钥依赖。
- 已有一个 `REACTBITS_LICENSE_KEY` 存在 Lovable 的密钥库里，但代码中并未使用，本地无需配置。

### 4. 验证

克隆后本地跑起来，逐屏检查：第一屏滚轮驱动的点阵手、第二屏黑屏反相、第三屏三列数字、第四屏大字与横向模块、最后一屏 dashboard 3D 翻转 + footer 上浮。素材全部本地化后这些都应正常。

## 技术说明

- 构建链：TanStack Start v1 + Vite + Tailwind v4，纯前端 SSR，部署目标是 Cloudflare Worker。
- Lovable 专用的 vite 配置包 `@lovable.dev/vite-tanstack-config` 会保留：它在本地 `vite dev` 下正常工作，无需替换。
- `.asset.json` 引用机制会被替换为 `public/media/*` 的静态路径，`src/assets/*.asset.json` 文件在改完后删除。
- 如果你以后想部署到 Vercel/Cloudflare 而不是 Lovable，构建命令仍是 `bun run build`，无需额外改动。
