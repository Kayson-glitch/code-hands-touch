# 第三屏第一张卡片看不到的问题

## 我的理解

问题不在卡片内部动画速度，而在**起始时机**：现在第三屏刚露头（视口 25% 处）进度就开始推进，第一列已经在往上走，所以还没等它稳定停在视野里就被带过去了。应该是第三屏进入并基本占满视口、再往下滚一段之后，卡片序列才开始。

## 调整方案

1. 把进度起点后移：`START_OFFSET_RATIO` 由 0.25 提到约 0.95，即第三屏顶部滚到接近视口顶部（模块被 pin 住）之后进度才从 0 开始。
2. 保留一段「静置区」：起点之后再留约 20% 视口高度的滚动量，让第一张卡片（点阵图 + 文案 + 数字）先完整可见并停留，之后才开始上移。
3. 轨道总长补偿：wrapper 高度加上前置静置量，保证三列的推进节奏和现在一致，最后一列结束的位置不变、不会提前留白。
4. 每列内部的位移速度、缓动、透明度渐变都不改。

只改起始时机与轨道长度，其他屏和布局、文案、配色不动。

## 技术细节

- `src/components/MetricsSection.tsx`：`START_OFFSET_RATIO`、`END_OFFSET_RATIO`、wrapper 高度计算（`cardHeight * CARDS.length` 加前置 hold），进度映射里在 0 前段加入 dead zone。
- 移动端与 `prefers-reduced-motion` 分支保持现状（直接完整显示）。
