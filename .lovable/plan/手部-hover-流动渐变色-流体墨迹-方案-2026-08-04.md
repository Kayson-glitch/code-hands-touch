# 手部 Hover：流动渐变色（流体墨迹）方案

放弃磁吸 / 加深 / 呼吸三种方案，改回之前调研 Speakeasy 时的思路：鼠标在手部区域移动时，像在纸面上推开一层带颜色的流体，网点的颜色随流体浓度从中性灰渐变到彩色，鼠标离开后颜色缓慢扩散、消散，回到原始灰阶。

关键点：只影响网点的颜色（以及极轻微的墨量），不改变半调网点的尺寸逻辑、滚轮驱动的帧推进、视差与入场链路。

## 效果描述

- 静止时：与现在完全一致的中性灰半调手部。
- 鼠标移动时：光标轨迹上出现一条柔和的彩色墨迹，边缘随流体自然扩散、拉丝，而不是一个硬边圆形。
- 停止移动：墨迹继续按惯性向前漂移一小段，再逐渐淡回灰阶（约 1.5–2.5 秒）。
- 颜色：默认使用低饱和暖色渐变（浅琥珀 → 橙 → 玫红），在灰阶纸面上克制但有存在感；实现时会把颜色抽成一个可调的渐变表，方便后续换色。

## 技术方案

1. 新增一个低分辨率流体场（约 96×54 的速度场 + 染料浓度场），与画布尺寸解耦，逐帧步进：
   - 指针移动时向速度场注入方向冲量，向染料场注入浓度；
   - 每帧做半拉格朗日 advection + 轻量扩散 + 衰减，得到自然的拖尾与扩散；
   - 不做压力投影（不需要严格无散度），保证 2D Canvas 下的性能。
2. 在现有网点绘制循环里，按网点中心坐标双线性采样染料浓度 `d`：
   - `d` 决定灰阶墨色与渐变色之间的混合比例（0 时完全等于现在的灰）；
   - `d` 额外给一个很小的墨量加成（上限约 +6% 半径），增强"被推过"的手感。
3. 流体场只在手部可见区域计算/绘制影响，避免空白纸面上出现无来源的色块。
4. 移除三方案切换器：删除 `hoverMode` 状态、切换器 UI、ripple 数组，以及磁吸/加深分支代码。
5. 保留：滚轮驱动帧推进与缓动惯性、视差、`INK_STOPS` 灰阶、入场视频与 UI 动画视频的交接逻辑。

改动集中在 `src/components/HalftoneHandsFooter.tsx`，流体场逻辑抽成同文件内的一个小模块以便调参。

## 验收

- 不移动鼠标时视觉与当前版本无差别。
- 移动鼠标产生连续、有惯性的彩色墨迹，无硬边、无块状马赛克。
- 滚轮驱动的手部动画与页面滚动交接行为不变。
