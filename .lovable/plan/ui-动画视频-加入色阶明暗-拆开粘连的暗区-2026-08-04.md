# UI 动画视频：加入色阶明暗 + 拆开粘连的暗区

只改 `src/components/HalftoneHandsFooter.tsx` 的渲染部分，滚轮驱动、帧序列、视差呼吸、入场链路全部不动。

## 1. 用颜色分担明暗（提升体积感）

现在所有点都是同一种中灰（`#a8` → `#8c`），体积感只能靠点面积。改为「面积 + 明度」双通道：

- 亮区（低密度）：浅灰，接近纸面，点小且淡。
- 中间调：中灰，维持现在的观感基准。
- 暗区（高密度）：明显更深的近炭黑，让掌心、指缝真正压下去。
- 同时给暗区加一丝极轻的冷色偏移（暗部偏石墨蓝、亮部偏暖中性），这是提升体积感最有效的一招，幅度很小，整体仍读作单色印刷，不会变成彩色插画。

实现上把当前的 `INK_LIGHT/INK_DARK` 两个标量换成一条按密度插值的三段色阶（浅灰 → 中灰 → 近炭黑），并保留 `sqrt(density)` 的面积响应，两者叠加而不是互相替代。

## 2. 拆开连成一片的暗区

参考图里红框位置：掌根与手指根部的高密度点已经方块化并互相咬合，糊成实心块，手指的分界消失。调整：

- 把方块化阈值 `SQUARE_AT` 从 0.75 提高（约 0.88），只有最深的少量点才方块化。
- 把方块化时的尺寸放大系数（现在 `1 + 0.14*sq`）取消或调为轻微收缩，让方块之间始终留出纸色缝隙。
- 把 `DOT_FILL` 从 0.98 降到约 0.9，给相邻点留白，即使全暗区也能看出网点栅格。
- 在高密度段对密度做一次轻微压缩（软上限，约 0.94 处收敛），避免大片区域全部顶到 1.0 变成同一个实心值。

结果：暗区仍然很深（靠颜色变深，而不是靠点变大糊住），但网点始终可辨，指缝重新出现。
