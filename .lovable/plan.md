当前颜色从 `shadow rgb(45, 35, 70)` 到 `highlight rgb(197, 169, 255)` 是线性映射 `bb`（`c.b`），暗部与亮部内部对比都较平。

目标：对亮度 `bb` 做分段非线性映射，使暗区和亮区各自的两端更拉开，同时保持整体紫色基调。

改动：
1. 在 `src/components/AsciiHandsFooter.tsx` 颜色计算前（当前第 574 行附近），新增一个 `remapLuminance(bb)` 函数：
   - 暗区（`bb < 0.5`）：`0.5 * pow(bb * 2, 0.7)` —— 深影更沉，中暗部稍提亮，形成暗区内部对比
   - 亮区（`bb >= 0.5`）：`1 - 0.5 * pow(2 * (1 - bb), 0.7)` —— 高光更亮，中亮部稍压暗，形成亮区内部对比
   - 保持 `bb=0 → 0`，`bb=0.5 → 0.5`，`bb=1 → 1`，中点连续
2. 将 `r = 45 + bb * 152` 等三行改为使用 `const b2 = remapLuminance(bb)` 后的值计算：`r = 45 + b2 * 152` 等。
3. 不改动 reveal/highlight 的混合逻辑（`HR/HG/HB` 混合仍基于 `sharpL`），只改变基础色的分布。
4. 参数可微调：幂指数 `0.7` 是起点，若太强烈可调至 `0.8` 或 `0.6`。

验证：
- `bun run build` 通过
- 预览截图：暗部手掌根部可见更深的阴影，亮部指尖可见更亮的高光，中间调过渡仍自然。
