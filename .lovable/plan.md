# 第三屏 1:1 复刻计划

## 目标

完整复刻 Kore.ai 参考模块 `enterprise-ai-outcomes` 的内容、布局、素材与滚动交互；唯一主动差异是将原站深色方案反相为当前项目的白底黑字，不改第一、二屏及现有 UI 动画。

## 实施内容

1. **替换第三屏全部内容**
   - 标题：`What { Artemis } changes for enterprise AI`
   - 三张卡片按原顺序使用完整原文：
     - `{ Outcomes in days }` / Artemis 基础设施说明 / `5x` / `faster time to value`
     - `{ Predictability at Scale }` / 上线前定义、测试与验证说明 / `No` / `surprises in production`
     - `{ Security + Governance }` / 策略、边界与可追溯说明 / `Zero` / `unauthorized agent actions`
   - 加入模块末尾原文：`{ Artemis } delivers certainty`
   - 使用参考站公开提供的 comet、value、scale、security 四个原始 SVG 素材，保存为项目本地资源，不在运行时外链。

2. **按原站参数重建版式**
   - 采用原站的 3 列无间隙网格、卡片与数字上下成组结构、容器宽度逻辑、sticky 顶部偏移、裁切区域和 footer 位置。
   - 还原标题图标、标题两行排版、卡片媒体区、正文区、1px 描边、48px 卡片/数字间隔和大数字比例。
   - 字体层级、字号、行高、内边距和响应式 clamp 直接对齐原站实际 CSS；保留项目现有导航高度作为 sticky 边界，避免遮挡。

3. **1:1 重建滚动交互**
   - 使用参考站真实公式：模块高度由 sticky 内容高度乘 3 构成，每列进度为 `clamp(0, progress × 3 − index, 1)`。
   - 每列从原站的 `20rem` 下方起始位移，线性上移到其内容顶部负偏移；透明度使用 `clamp(0, columnProgress × 3, 1)`。
   - 三列依次进入、卡片上移离场、对应结果数字停入视口；支持反向滚动并在最后一列完成后自然释放 sticky。
   - 还原原站末尾文案与 sticky 释放时的衔接，而不是只保留数字终态。

4. **仅做白底黑字适配**
   - 第三屏背景继续使用项目当前白色背景，主文字改为黑色，辅助文字使用现有浅色主题语义色。
   - 卡片边框、图形和素材在白底下保持清晰；不引入参考站黑色背景。
   - 第三屏期间导航和底部对话框继续使用项目现有浅色状态。

5. **响应式与验证**
   - 桌面端严格保留三列 sticky 动画；小于原站桌面断点时切换为参考站的单列静态/自然流布局，避免窄屏裁切。
   - 在 1440px 标准设计宽度及当前预览尺寸逐段截图核对：初始、每列进入、数字停位、footer 出现、回滚五个状态。
   - 检查无文字溢出、素材加载失败、导航/对话框遮挡或滚动跳变，并验证 reduced-motion 降级状态。

## 技术说明

- 主要重写 `MetricsSection`，页面中的第三屏接入位置不变。
- 复刻依据为参考页当前公开 DOM、CSS 与实测渲染尺寸；不再沿用现有虚构文案、灰色占位图及基于视口高度估算的位移模型。
- 不修改第一屏手部、UI 动画视频、第二屏内容、导航视觉或底部对话框功能。
