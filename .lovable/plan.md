# 第三屏点阵图快速掠过的问题

## 我的理解

你指的是首页第三屏（What { Artemis } changes）里每张卡片顶部那张渐变点阵图。现在滚动经过时，点阵图还没来得及看清就被向上带走/裁掉了，看不到它完整停留的状态。

## 原因（当前实现）

- 整段轨道高度 = 单张卡片高度 × 3（约 2500px），进度 0→1 后每一列只占整段的 1/3，单列位移时间很短。
- 每一列从 +320px 升到 `-copyTop`（把文案顶到容器顶部），卡片高度大于粘性区剩余可视高度，点阵图升上去后立刻被 `overflow: hidden` 裁掉，所以只有「路过」的一瞬间能看到。
- 进度起点偏早（视口 25% 处就开始推进），第三屏刚露头动画就已经在跑。

## 调整方案

1. 拉长滚动轨道：把 wrapper 高度系数提高（每列约 1.35 倍卡片高度），单列的位移速度明显变慢。
2. 每一列加入「停留段」：列进度前 ~65% 做位移，后 ~35% 保持不动，让点阵图和数字在到位后有停顿再交给下一列。
3. 进度起点后移（START_OFFSET_RATIO 由 0.25 调到约 0.45），等第三屏基本进入视口并被 pin 住后再开始推进。
4. 微调列的终点位移，保证点阵图在停留段内仍有一部分可见，而不是一升上去就被裁掉。

只改动画时序与轨道长度，不改布局、文案、配色和其他屏。

## 技术细节

- `src/components/MetricsSection.tsx`：`START_OFFSET_RATIO`、wrapper 高度计算、`columnProgress` → 加 hold 段的映射函数、`translateY` 终点。
- 移动端与 `prefers-reduced-motion` 分支保持现状（直接完整显示）。
