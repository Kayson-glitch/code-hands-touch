## 目标
把当前 ASCII 手掌的紫色基色从 `#733BFF` 换成 `#BA9EFF`（更亮、更偏薰衣草紫），观察新效果。

## 范围与不变项
- 只改颜色常数，不动生长路径、骨架、动效、交互或任何业务逻辑。
- 保持可回退：原紫色值注释保留，可一键切回。

## 实现步骤
1. **调整基色色阶**
   - 高光：`rgb(186, 158, 255)` (#BA9EFF)
   - 暗部：低饱和深紫 `rgb(30, 20, 55)`，保持明暗结构
   - 差值插补：
     - r: 30 + bb * 156
     - g: 20 + bb * 138
     - b: 55 + bb * 200
2. **调整高亮色**
   - 将 hover/intro 高亮 `HR/HG/HB` 从 `235, 225, 255` 改为 `245, 235, 255`，更贴近 #BA9EFF 的亮感。
3. **修改 `src/components/AsciiHandsFooter.tsx`**
   - 更新 `// Base purple color` 注释与 RGB 计算。
   - 更新高亮注释与 RGB 常量。
4. **构建验证**
   - 运行 `bun run build` 通过。
   - Playwright 截图确认页面加载后呈现薰衣草紫色。

## 预期结果
- 手掌整体更明亮、偏淡紫，暗部保留一定层次。
- 悬停前沿高亮与 #BA9EFF 色相一致。
