## 缓动曲线与时长调整

### 目标
- 起始阶段：指尖位置先浮现一圈小光环，停留一小段时间
- 中后段：黑孔加速外扩至全屏
- 整体节奏更接近"指尖触发 → 光点扩散"的电影感

### 修改（仅 `src/components/IntroVideo.tsx`）

1. **时长加长**
   - `BURN_DURATION_MS`: `2600` → `3600`

2. **半径缓动改为 easeInQuart（慢起快收）**
   - 当前：`r = (1.0 - pow(1.0 - b, 3.0)) * 1.9`（easeOutCubic，起步就快）
   - 改为：`r = pow(b, 3.2) * 2.05`
     - `pow(b, 3.2)` 让前 40% 的时间半径只涨到最终值的 ~7%，形成"指尖光点驻留"感
     - 尾段（b > 0.7）指数曲率放大，黑孔迅速吞满屏幕
     - 终值放大到 `2.05`（原 1.9）确保 3.6s 内屏幕四角也被覆盖

3. **起始锚点显性化**
   - 保留 `appear = smoothstep(0.0, 0.08, b)`（把淡入区间收紧）让光环在指尖位置立刻可见
   - 亮环宽度 `ringWidth` 保持 `0.10`，其扫过的能量密度自然由半径速率决定——慢时环像"呼吸的光点"，快时变成锐利的推进面

### 不变项
- 单一半径同时驱动黑孔与亮环（同步）
- fbm 边缘扰动、颜色、触发/锁定/滚动逻辑
- `onEnded` 触发时机（burn 结束后进入手部场景）

### 验证
build 后跑 Playwright 脚本，在 burn 起始的 0.3s / 0.9s / 1.6s / 2.4s / 3.2s 各截一张（1280×1800），确认：
- 早期帧（0.3s、0.9s）：屏幕基本仍是视频最后一帧，指尖处有一个小亮环
- 中段帧（1.6s）：环+黑孔明显扩张
- 后段帧（2.4s、3.2s）：黑孔快速吞满屏幕
