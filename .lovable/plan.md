## 目标
放大 hover 时的视差幅度，让手掌的"跟随光标漂移 + 深度分层"更明显。

## 修改文件
`src/components/AsciiHandsFooter.tsx`

## 调整
1. `PARALLAX_MAX`：`8` → `18`（整体位移幅度加大 2 倍多）。
2. 深度层次拉开——把每 cell 的 `depth` 公式：
   ```
   0.35 + bb * 0.45 + c.armT * 0.35     // 现状：暗根 0.35x，亮指尖 ~1.15x
   ```
   改为
   ```
   0.25 + bb * 0.65 + c.armT * 0.55     // 暗根 0.25x，亮指尖 ~1.45x
   ```
   → 亮部/指尖位移显著大于暗部/手根，立体感更强。
3. `PARALLAX_LERP` 保持 `0.08`（跟手感继续柔顺），如果幅度加大后觉得慢，可在下一轮微调到 `0.1`。

其余（tilt、reveal tilt、smoothstep 衰减）不变。

## 验证
`bun run build` 通过；Playwright 光标在左右手、边缘位置分别停留，观察手掌位移比之前明显、且指尖比手根位移更大。
