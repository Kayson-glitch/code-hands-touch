## 目标
把当前 hover reveal 的破碎/锯齿边缘，改回**接近圆形**但仍带有轻微不规则起伏——像手绘的圆，不是墨溅碎片。其余（80px 直径、跟随、视差、字符倾斜、马赛克揭示、生长动画、紫色主题）保持不变。

## 改动范围
仅调整 `src/components/AsciiHandsFooter.tsx` 中控制 reveal 边缘噪声的几个常量与权重，不动结构、不动其它效果。

## 具体调整
1. **降低总噪声幅度**：`GOOEY_NOISE` 从 `0.018` → `0.006` 左右，让边缘偏离圆的距离整体收窄。
2. **弱化中/高频扰动**（这是"碎"的主要来源）：
   - `midFreq` 系数从 `× 5` → `× 1.2`，只保留一个缓慢的大波浪。
   - `highFreq`（两个 hash 项）系数从 `× 1.0 / × 0.5` → `× 0.15 / × 0.1`，几乎消除颗粒锯齿。
3. **降低方向性偏置**：`DIRECTIONAL_BIAS` 从当前值降到 `0.25` 左右，使沿手臂轴向的"拉长"减弱，形状更接近圆。
4. **略微收紧柔化带**：`GOOEY_SOFTNESS_UV` 保持或略降 (`0.023` → `0.020`)，让边界仍柔和但不糊。
5. **马赛克 shatter 边缘同步降幅**：`MOSAIC_SHATTER_PX` 从 `3` → `1.5`，`MOSAIC_SCALE_MIN` 从 `0.72` → `0.88`，让边缘方块只轻微错位，符合"近圆"观感。

## 验证
Playwright 悬停截图三态（静止 / 慢移 / 快移），确认：
- 轮廓视觉上是圆，但边缘有 1–2 像素级别的柔和起伏（非锯齿、非墨溅）。
- 直径仍约 80px，跟随/视差/字符倾斜/马赛克揭示行为不变。
