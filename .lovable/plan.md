## 目标
让鼠标移入/移出时 reveal disc 的显现和位置跟随更平缓，减少突兀感，使破碎边缘像缓慢扩散/收起的墨水。

## 改动内容
1. **减缓 hover 强度淡入淡出**
   - `INTENSITY_LERP` 从 `0.08` 降到 `0.05` 左右，让 reveal 从 0 到 1 的过渡耗时更长，边缘破碎感随强度缓慢建立。

2. **减缓 disc 对光标的跟随**
   - `DISC_LERP` 从 `0.12` 降到 `0.08` 左右，使盘在光标移动时略有滞后，边缘的破碎纹理在移动中更连贯、不跳。

3. **不改动**
   - 盘大小 `GOOEY_RADIUS_UV = 0.0376`（80px 等效）
   - 噪声参数（`GOOEY_NOISE` 及其多层混合）
   - 明暗关系加权 `lumaWeight`
   - 基础颜色、字体、采样

## 验证
- `bun run build` 通过。
- Playwright 截图/录制：快速移入、移出、划过手掌，确认 reveal 不再瞬间出现，而是缓慢铺开；破碎边缘随光标移动有柔和拖尾，无卡顿或抖动。
