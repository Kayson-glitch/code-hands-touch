# 手部改为「滚轮驱动播放」的视频半调点阵

用上传的视频（4.04 秒，24fps，97 帧，1284×716，纯白底、双手从左右伸入）替换现在的静态图，逐帧转成半调点阵；不自动循环，播放进度完全由鼠标滚轮/滚动控制。页面其他部分（开场视频、导航、文案、第二屏、对话条）不动。

## 行为

- 开场视频结束后，点阵停在第 1 帧（画面基本空白，手还没伸进来）。
- 向下滚动 → 帧号前进，双手从两侧伸入并靠近；向上滚动 → 反向倒退。滚动停止即停帧，不会自己继续播。
- 滚动映射：首屏那一段滚动距离（现有 100vh 占位）线性对应第 1 帧到最后一帧，手在第二屏（Slogan）开始上移时正好完成。
- 帧号做插值平滑（每帧向目标帧缓动），避免滚轮的离散跳跃感。
- `prefers-reduced-motion` 下直接固定显示最后一帧。
- 轻微视差与呼吸保留，但幅度调低，避免和滚轮驱动的位移打架。

## 素材处理

视频不直接在页面里播放（逐帧 seek 不稳、还会卡）。改成离线预处理：

- 用 ffmpeg 把视频抽成 49 帧（每 2 帧取 1，约 12fps，足够顺）。
- 拼成一张灰度雪碧图（每帧宽 320px，7 列 × 7 行），导出为 WebP，体积预计 100–200KB，远小于原视频的 940KB。
- 通过 lovable-assets 上传为 `hands-frames.webp` 资源指针，替换现有 `hands-pair.png`（旧资源不再引用）。

## 渲染改动（`src/components/HalftoneHandsFooter.tsx`）

- 采样源从单张图改为雪碧图中的某一帧区块：`drawImage(atlas, sx, sy, fw, fh, 0, 0, cols, rows)`。
- **反相**：新素材是白底深色主体，密度改为 `1 - luma`（现在的逻辑是深底浅主体，直接用会出反效果）。
- 白底部分（接近纯白）低于阈值即完全不画点，保证 `#FAFAFA` 纸面干净。
- 保留现有的半调风格：单一中灰墨色、面积正比于密度、暗部方块化、外圈孤点飞散、4×4 有序抖动。
- 每帧只在「目标帧变化 或 呼吸/视差变化」时重采样，重采样结果按帧缓存，滚动来回不重复计算。

## 验收

Playwright 模拟滚动到 0%、35%、70%、100%，各截一张手部区域：确认手是从两侧逐步伸入、白底无杂点、暗部方块化、反向滚动能倒退。
