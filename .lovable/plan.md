## 目标

1. 让 hover 马赛克更精致（缩小碎片尺寸）
2. 提供 4 种破碎形状方案，通过一个浮动调试面板实时切换

## 改动范围

仅修改 `src/components/AsciiHandsFooter.tsx`（新增一个小型调试面板 UI + 形状参数分支）。图片资源、加载动画、颜色、视差、字符流动等其它效果保持不变。

## 一、缩小马赛克尺寸

当前每个马赛克瓦片 ≈ 一个字符格（约 8–10px）。将其细分为 2×2 子格渲染：

- 每个字符格内绘制 4 个更小的图片碎片
- 抖动 / 缩放 / 位移基于子格坐标各自独立随机
- 视觉尺寸从 ~9px 降到 ~4.5px，细节感更强
- 边缘残留的字符层保持不变，作为过渡

## 二、4 种形状方案

调试面板中通过单选切换 `revealShape`，影响 reveal 强度场 `intensity(u,v)` 的形态：

| 方案 | 说明 | 强度场公式要点 |
|---|---|---|
| A. 不规则墨迹圆（当前） | 圆形基底 + 多层噪声破碎 | `1 - r` + noise(低/中/高频) |
| B. 沿手臂延展椭圆 | 沿最近手臂骨骼方向拉伸，法线方向压扁；碎片沿法线飞溅 | 各向异性距离：`sqrt((d∥/1.6)² + (d⊥/0.7)²)` |
| C. 菱形/钻石碎裂 | 菱形基底（L∞ 距离旋转 45°），尖角方向溅射长碎片 | `1 - (|du|+|dv|)` + 尖角处 noise 增强 |
| D. 有机变形 blob | 低频 Perlin/hash 噪声驱动的缓慢呼吸轮廓 | `1 - r*(1 + 0.35*noise(θ, t*0.4))` |

所有方案共享：
- 相同的 lerp 跟随、速度自适应
- 相同的马赛克瓦片渲染（含新的 2×2 细分）
- 相同的 68/80px 基础半径
- 相同的字符倾斜、视差、明暗保留逻辑

## 三、调试面板

固定位于组件容器右上角（`position: absolute; top: 12px; right: 12px`），仅在开发时有用，样式低调：

- 半透明黑底、白字、小号 pill
- 标题 `Reveal Shape`
- 4 个 radio: A / B / C / D
- 一个滑块：`Mosaic Sub-grid`（1 = 当前尺寸，2 = 默认新尺寸，3 = 更细）
- 状态存在组件内 `useState`，通过 `ref` 同步给 canvas 主循环，避免重渲染

面板可通过一个 prop `showControls`（默认 `true`）关闭，方便发布时隐藏。

## 技术要点

- 新增 `shapeRef.current: 'A'|'B'|'C'|'D'` 与 `subGridRef.current: number`，在 rAF 循环中读取
- 强度场函数抽成 `computeReveal(du, dv, armAngle, t)`，按 shape 分支
- 马赛克绘制循环增加 `for (sy=0; sy<sub; sy++) for (sx=0; sx<sub; sx++)`，`tileW = cellW/sub`
- 采样源图坐标从 `(gx, gy)` 精细化到 `(gx + sx/sub, gy + sy/sub)`
- B 方案的"最近手臂方向"复用现有骨骼数据（人类臂 / 机械臂 anchor）
