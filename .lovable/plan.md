# 用半调点阵手部替换现有 ASCII 手部

放弃 ASCII 字符 + 流体墨迹方案，按参考图 1:1 重做：近白背景上由灰度圆点组成的一对手，边缘向外逐渐稀疏消散。除手部渲染外，页面其他部分（开场视频、导航、文案、第二屏、对话条）完全不动。

## 视觉目标（对照参考图）

- 背景保持 `#FAFAFA`，无任何色彩，只有中性灰点。
- 手由规则网格上的圆点组成，点大小随源图明暗变化：亮处点小而淡，暗处点大而近炭黑。
- 手腕/画面外侧边缘的点逐渐变小、变稀，自然溶进背景，不留硬边。
- 不再有字符、不再有色块、不再有流体染色。

## 交互

轻微视差 + 呼吸：

- 鼠标移动时整片点阵做极小幅度（几个像素级）位移，靠近的一侧位移更明显。
- 点的整体明暗做缓慢的低幅呼吸，让画面不死板。
- 不做局部聚焦、不做颜色、不做点击响应。

## 要删除的旧样式

`AsciiHandsFooter.tsx` 内与新方案无关的逻辑全部移除：字符坡（RAMP/INK/CUTOFF）、明暗曲线与抖动、分指连通域与指缝检测、轮廓判定、字形流动波、流体速度场与染料场（dye/velocity）、以及相关常量与调试面板挂钩。文件更名为点阵组件，`src/routes/index.tsx` 只改这一处 import 与标签名。

## 技术方案

- 新组件 `src/components/HalftoneHandsFooter.tsx`，接口与现有组件保持一致（`videoSrc`、`debug`、`handoffVideo` 原样透传给内部的 `IntroVideo`），所以开场视频链路一行都不改。
- 单个 `<canvas>`，DPR 自适应。离屏 canvas 把 `hands-pair.png` 采样成网格亮度图（网格间距约 6–8 CSS px，按视口自适应）。
- 每格计算 `d = 1 - luma`，点半径 `r = maxR * pow(d, ~0.8)`，低于阈值不画点；颜色为固定中性灰阶（由 d 映射到 ~#111 至 ~#c9c9c9），保证明暗跨度但不出现彩色。
- 边缘消散：在画面左右外侧与手腕方向叠加一个衰减遮罩，并按格子加入稳定随机抖动阈值，使点在边界处随机缺失而不是整排消失。
- 每帧只在鼠标位移或呼吸相位变化时重绘；`prefers-reduced-motion` 下取消视差与呼吸，画静态一帧。
- 保留 `debug` 入参（不再驱动旧的 burn 面板逻辑，仅用于显示网格参数），若旧调试面板只服务 ASCII 方案则一并解绑。
