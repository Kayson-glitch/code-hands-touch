# 暗色模式手部提亮 + 取消页面栅格线

## 现状
- 暗色皮肤下的半调手部是把浅色墨阶直接取反算出来的（`INVERTED_INK` 把 `INK_STOPS` 做 `255 - c`），得到的点约为 #171717–#575757，压在 #0A0A0A 纸面上，明暗差极小，所以整体发闷、看不出体积。
- 第一屏画面上那层横向细线来自 `GlitchGrainOverlay`（1px 白线、3px 间隔的重复渐变），在 `HalftoneHandsFooter` 里以 `intensity="low"` 常驻，在黑底上比浅底更明显。

## 要做的事

### 1. 暗色模式单独一套墨阶
不再用取反公式，而是给暗色皮肤配一组独立的墨色停靠点，让最暗区的点足够亮、亮区的点接近纸面：
- 浅色（保持不变）：#E8E8E8 → #C8C8C8 → #A8A8A8
- 暗色（新增）：约 #3A3A3A → #8C8C8C → #EDEDED（近纸面 → 深阴影处最亮）

`inkAt()` 改为按当前皮肤选择对应的停靠点数组插值，两套曲线的分段方式保持一致，因此点面积、方形化阈值、呼吸与流体墨迹逻辑都不用改。切换皮肤时仍走现有 300ms 过渡。

### 2. 取消页面栅格线
移除 `HalftoneHandsFooter` 中常驻的 `GlitchGrainOverlay`（连同不再需要的导入）。组件文件本身保留，入场视频里的扫描线效果不受影响。

## 技术细节
- `src/components/HalftoneHandsFooter.tsx`
  - 新增 `INK_STOPS_DARK`，`inkAt()` 依据 `INVERTED_INK` 取用对应停靠点，删掉 `255 - c` 镜像。
  - 删除第 974 行的 `<GlitchGrainOverlay visible intensity="low" />` 与第 5 行的导入。
- 不改动纸面色（`#0A0A0A` / `#FAFAFA`）、阈值翻转逻辑、视频逐帧滚动、ghost 入场层。

## 验证
在 1460px 视口下滚动触发暗色翻转，对手部区域做局部截图，确认点阵层次清晰、无横向细线；再回滚确认浅色形态未变。
