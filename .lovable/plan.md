# 第二屏背景反相：改为阈值触发 + 瞬时切换

## 目标

1. 背景/文字变色不再跟随滚动进度连续插值（当前是 scroll-scrub 渐变，会“跟着滚轮走”）。
2. 触发点改为：第二屏在视口中露出约 20% 时立刻切换到黑底白字；向上回滚时同样在该阈值处切回浅色。
3. 切换本身用一个短的 CSS 过渡（约 250–350ms ease），做到“瞬时、干净”，与 kore.ai 那种分段式换色一致（滚动只决定“是否越过阈值”，不决定颜色进度）。

## 行为定义

- 阈值：第二屏顶部进入视口底部以上 20% 视口高度处，即 `rect.top <= vh * 0.8` → 深色；`rect.top > vh * 0.8` → 浅色。
- 为避免在阈值附近反复抖动，加入约 40px 的滞回（进入用 0.80，退出用 0.84）。
- 文字反相与背景同一开关驱动，同步过渡；文字逐字揭示动画保持不变。
- 尊重 `prefers-reduced-motion`：直接取最终状态，无过渡。

## 技术要点

- 文件：`src/components/SloganSection.tsx`
  - 移除现有基于 `own` 进度的 `smoothstep(0.34, 0.46, own)` 连续插值和 `mix()` 颜色计算。
  - 改为布尔 state `dark`，在已有的滚动 rAF 回调里按上面的阈值/滞回更新。
  - 背景与文字颜色直接给两个固定值（`#FAFAFA` / `#0A0A0A` 与反相），配合 `transition: background-color 300ms ease, color 300ms ease`。
- 第一屏 `100dvh` 撑满一屏的逻辑不动，滚动劫持/帧序列逻辑不动。

## 验证

用 Playwright 在 1280 视口逐步滚动，检查阈值前后 `section` 的 `background-color` 与文字色是否在同一位置整体切换，并确认回滚可还原。
